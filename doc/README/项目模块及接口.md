# 项目模块及接口

## 一、接口说明

后端地址：`http://localhost:8082`

后台管理端通过 `/api` 代理访问后端。例如后台请求 `/api/admin/login`，实际转发到后端 `/admin/login`。

接口返回通常采用以下结构：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

常见业务状态码：

| code | 含义 |
| --- | --- |
| 200 | 请求成功 |
| 400 | 参数错误或业务规则不满足 |
| 401 | 未登录或 Token 无效 |
| 403 | 无权限操作 |
| 404 | 资源不存在 |
| 500 | 服务器或第三方服务异常 |

需要登录的接口一般通过 `token` 或 `Authorization` 请求头传递用户 Token；管理员接口使用管理员 Token。

## 二、用户与登录模块

| 方法 | 接口 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | `/user/login` | 简易登录，返回测试 Token | 无 |
| POST | `/user/wxlogin` | 使用微信 code 登录，首次登录自动注册用户 | 无 |
| GET | `/user/info` | 获取当前用户信息 | 用户 Token |
| POST | `/user/update` | 修改昵称、头像、性别、生日、手机、邮箱 | 用户 Token |
| GET | `/user/list` | 分页查询用户，可按昵称、手机号、状态筛选 | 管理员 |
| GET | `/user/{userId}/orders` | 查询指定用户的历史订单 | 管理员或按接口权限 |

重点测试：微信 code 一次性、Token 缺失、Token 失效、重复注册、用户资料边界值和用户越权。

## 四、民宿和房型模块

### 1. 民宿接口

| 方法 | 接口 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | `/homestay/list` | 分页查询民宿，支持名称和状态筛选 | 前台可用，后台使用 |
| GET | `/homestay/{id}` | 查询民宿详情 | 无 |
| POST | `/homestay/create` | 新增民宿 | 管理员 |
| PUT | `/homestay/update/{id}` | 修改民宿信息 | 管理员 |
| DELETE | `/homestay/delete/{id}` | 删除民宿及关联房型 | 管理员 |
| PUT | `/homestay/toggleStatus/{id}` | 切换民宿上下架状态 | 管理员 |

### 2. 房型接口

| 方法 | 接口 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | `/room/list` | 分页查询房型，支持民宿、名称、床型、状态和价格区间筛选 | 无或登录用户 |
| GET | `/room/count/{homestayId}` | 查询民宿下的房型数量 | 无 |
| GET | `/room/{id}` | 查询房型详情 | 无 |
| POST | `/room/create` | 新增房型 | 管理员 |
| PUT | `/room/update/{id}` | 修改房型信息 | 管理员 |
| DELETE | `/room/delete/{id}` | 删除房型 | 管理员 |
| PUT | `/room/toggleStatus/{id}` | 切换房型上下架状态 | 管理员 |
| GET | `/room/calendar` | 查询指定房型日期范围内的价格、库存和房态 | 无或登录用户 |
| GET | `/room/{id}/reviews` | 查询房型已审核通过的评价 | 无 |

重点测试：分页、筛选组合、上下架状态、民宿与房型关联、价格边界、库存为 0、日期范围和级联删除。

## 五、订单模块

| 方法 | 接口 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | `/order/create` | 创建待支付订单 | 用户 Token |
| POST | `/order/batch-create` | 批量创建订单，直接生成已支付订单 | 用户 Token |
| GET | `/order/list` | 分页查询订单 | 管理员查全部，用户查本人 |
| GET | `/order/{id}` | 查询订单详情 | 管理员或订单本人 |
| PUT | `/order/{id}/status` | 修改订单状态 | 管理员或订单本人 |
| PUT | `/order/{id}/cancel` | 取消订单 | 管理员或订单本人 |

订单状态：

| 状态值 | 含义 |
| --- | --- |
| 0 | 待支付 |
| 1 | 已支付 |
| 2 | 入住中 |
| 3 | 已完成 |
| 4 | 已取消 |
| 5 | 已退款 |

重点测试：金额计算、入住日期和离店日期、订单归属、状态流转、重复提交、取消条件和越权访问。

## 六、评价模块

| 方法 | 接口 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | `/review/list` | 分页查询评价，支持房型名称和审核状态筛选 | 管理员 |
| GET | `/review/user` | 查询当前用户评价 | 用户 Token |
| POST | `/review/create` | 提交评价 | 用户 Token |
| DELETE | `/review/{id}/delete` | 删除本人评价 | 评价作者 |
| PUT | `/review/{id}/update` | 修改未通过的评价并重新提交审核 | 评价作者 |
| GET | `/review/{id}` | 查询评价详情 | 无 |
| GET | `/review/{id}/detail` | 查询增强版评价详情 | 无 |
| POST | `/review/{id}/approve` | 审核通过评价 | 管理员 |
| POST | `/review/{id}/reject` | 审核拒绝评价 | 管理员 |

评价状态：0 待审核、1 已通过、2 未通过。

重点测试：评分 1 到 5 的边界、订单归属、同一订单重复评价、评价作者权限和管理员审核权限。

## 十、文件上传模块

| 方法 | 接口 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | `/upload/image` | 上传 jpg、png、webp 图片 | 当前接口未强制登录 |

上传限制：单个文件不超过 5MB，返回的图片地址通常为 `/images/文件名`。重点测试空文件、非法后缀、超过大小、重复文件名和未登录上传。

## 十一、核心测试优先级

建议按照以下顺序熟悉和测试：

1. 微信登录和 Token 鉴权。
2. 民宿、房型列表和详情。
3. 创建订单、订单查询和取消。
4. 评价提交和管理员审核。
5. 收藏、购物车和用户越权。
6. 后台数据看板和资讯管理。
7. 图片上传、推荐接口和性能测试。
